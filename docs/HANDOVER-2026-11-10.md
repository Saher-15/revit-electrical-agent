## What was learned and where it lives in the code
- WP families need `Symbol offset = 0` (case varies) → office.json `placement.instanceParams`, case-insensitive parameter lookup (C#).
- Provenance tags are appended to Comments, never replacing the designer's text → `appendParameters` (C#), `provenance` argument of `apply_electrical_design`.
- Worksets per category → office.json `placement.worksets`, `workset` on placements (C#).
- Template devices below the unit floor belong to another floor → ignored in `buildUnit` with a warning.
- Wall above a door head is valid (heater socket over the bathroom door); wet zones end at 2250 mm → `hostingConstraints`.
- Wall devices sit inside the wall thickness and were missed by room containment → PR #4 (nearest room within 400 mm).
- Engineer's defaults for bathrooms, laundry, master bedroom and the full mounting-height table → `skill/design-by-example/references/room-rules.md`.
- Working mode with the engineer: no own additions without instruction; every instruction is applied exactly and recorded as a project rule (RULES.md) and, when general, in room-rules / lessons.
