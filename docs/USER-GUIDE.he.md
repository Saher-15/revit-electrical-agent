# מדריך למתכנן/ת: Claude ב-Revit (חשמל)

מסמך מסירה קצר. מקורו: `skill/design-by-example/SKILL.md`, כללי הפרויקט ו-`ROLLOUT-PLAN.he.md`.

## 1. איך עובדים (יום עבודה)
1. פותחים את המודל ב-Revit, Add-Ins › Claude Chat. Claude טוען את `RULES.md` ואת `office.json`.
2. **מתכננים ידנית דירה אחת או חדר אחד** (הדוגמה). זה החלק שלכם.
3. אומרים ל-Claude איזו יחידה היא הדוגמה ואילו קומות/דירות להשלים.
4. Claude קורא את הדוגמה ומסביר במילים מה הבין (סוגי חדרים, ריהוט, התקנים). **עונים כן/לא ומתקנים.**
5. Claude מציע תוכנית: כמה נקודות, כמה הוזזו, כמה נשמטו ולמה. **רק אחרי אישור** הוא מניח במודל, בקבוצות של עד 5.
6. עוברים על התוצאה: כחול = נגזר מהדוגמה, כתום = תכנון של Claude. תיקון שלכם הופך לכלל.

## 3. מה לשאול את Claude
- "מה הבנת מהדירה הזאת?"  ·  "למה הנקודה הזאת נשמטה / הוזזה?"
- "הצג תצוגה מקדימה לפני שאתה מניח."  ·  "חזור על התיקון בכל הדירות שנבנו מאותו כלל."
- "מה אחוז הנקודות שאושרו ללא שינוי?" (יעד: 95% ומעלה)

## 4. מה אסור
- **לא Save ולא Sync.** המתכנן/ת שומר/ת בעצמו/ה. במודל ענן (ACC) עובדים על עותק מקומי.
- Claude נוגע רק בקטגוריות חשמל. קירות, תקרות, חדרים ורשתות הם לקריאה בלבד.
- אסור להפעיל `send_code_to_revit` (חסום ב-managed-settings).
- לא להעלות ל-Claude מידע לקוח שהוצא מהמשרד: רק חשבון Team/Enterprise של טופז.
- לא לשנות `RULES.md` ביד בתיקייה המשותפת: כללים חדשים נכנסים ל-`RULES.proposed.md` ומאושרים על ידי אחראי/ת הפרויקט.

## 5. כללים שלמדנו מעביר (דירה לדוגמה, 10/11)
גבהים מהרצפה המוגמרת עד ציר ההתקן, בס"מ: מפסק רגיל/חילוף 120 · מעל שידת לילה 60 · מפסק דוד 150 · פקט מוגן מים 150 · טלוויזיה 170 · מזין תריס 260 · עמדת עבודה 40. התקני תקרה צמודים לתקרה (230 בחדרי רחצה ובתקרה מונמכת, 273 בשאר). הרשימה המלאה: `RULES.md` של הפרויקט.
