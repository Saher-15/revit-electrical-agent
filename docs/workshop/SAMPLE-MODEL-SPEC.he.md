# מפרט מודל דוגמה לסדנה (נקי מנתוני לקוח)

חומר שעדיין **לא קיים**; צריך לבנות אותו. לא להשתמש במודל KYM-EL-101-5 (מידע לקוח, ראו שאלת הנהלה "מותר להציג תמונות").

## דרישות
- קובץ Revit בלי קישור לפרויקט לקוח, שם כללי ("Workshop-Sample").
- קומה אחת ו-3 דירות דומות (דוגמה + 2 להשלמה), אחת במראה.
- אדריכלות מקושרת: קירות, דלתות, חלונות, ריהוט (מיטה, ארון, שולחן, מטבח, חדר רחצה).
- דירה 1 (הדוגמה) מתוכננת ידנית: מפסקים 120, שקעים 30, תאורת תקרה, מפסק דוד 150.
- `office.json` לדוגמה בתיקיית המודל, ו-RULES.md קצר.
- 2 מלכודות בכוונה: ארון מול קיר (נשמטת נקודה) וחדר רחצה (אזור רטוב).
