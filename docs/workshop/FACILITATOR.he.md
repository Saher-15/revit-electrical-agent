# תסריט למנחה: סדנת 90 דק' (Design by Example)

השלם את `README.he.md`. כל שלב: מה אומרים, מה עושים, מה צפוי, ומה עושים אם נכשל. **לא נוסה בסדנה בפועל.**

## הכנה (יום לפני, 30 דק')
- [ ] כל משתתף: Revit נפתח, Add-Ins › Claude Chat עונה ל"שלום" (`say_hello`).
- [ ] מודל הדוגמה פתוח כעותק מקומי (מפרט: `SAMPLE-MODEL-SPEC.he.md`), בלי Sync.
- [ ] `office.json` לדוגמה בתיקייה המשותפת, `REVITCLAUDE_ROOT` מוגדר.
- [ ] גיבוי: צילומי מסך של כל שלב (למקרה שחיבור נופל).

## 0-15: מושגים
**אומרים:** "מתכננים דירה אחת ביד, Claude לומד את הכללים ממנה ומשלים את שאר הקומה. אתם מאשרים לפני כל הנחה."
**מראים:** שלושת השערים (קריאת הדוגמה, הצעה, כלל חדש) ו"מה אסור": Save, Sync, `send_code_to_revit`, מידע לקוח.
**שאלת בדיקה:** "מה Claude לא עושה בלי כן שלכם?" (מניח במודל, שומר כלל).

## 15-30: הדגמה חיה
פקודות למשתתפים להקליד (בעברית):
1. "ייצא snapshot של קומה 02 עם ארכיטקטורה." ← צפוי: קובץ JSON, ספירת חדרים ואלמנטים.
2. "קרא את דירה 1 כדוגמה ותגיד מה הבנת." ← צפוי: רשימת חדרים, מיטה/ארון/דלתות, נקודות לפי תפקיד.
3. "למד את הכללים והצג אותם במילים." ← צפוי: טבלת כללים (גובה, מרחק מדלת).
4. "הצע תכנון לדירה 2 בלי להניח." ← צפוי: תצוגה מקדימה וספירות: מוצבו, הוזזו, נשמטו + סיבות.
**אם נכשל:** "connect to revit client failed" ← Add-Ins › Revit MCP › Open Server. שגיאה אחרת: מציגים את צילום המסך המוכן.

## 30-60: תרגול (משתתפים)
חלוקה לזוגות. מחלקים `PARTICIPANT-HANDOUT.he.md`. המנחה עובר בין זוגות ושואל: "למה Claude הזיז את הנקודה הזאת?". נקודת עצירה בדקה 45: זוג אחד מספר מה מצא.
**סימן אזהרה:** משתתף לוחץ Save או Sync ← עוצרים, מזכירים את הכלל.

## 60-80: ביקורת וכלל חדש
1. משתתף מתקן נקודה אחת ידנית.
2. מנסח כלל ("מפסק ליד דלת, 120 ס"מ"). Claude חייב לכתוב אותו ל-`RULES.proposed.md` עם מקור ולהמתין לאישור.
3. מבקשים: "חזור על התיקון בכל הדירות שנבנו מאותו כלל." מראים שהכלל חל גם על דירה 3.

## 80-90: מדידה וסיום
- פותחים `run-report.json` ומראים כיסוי, זמן, כשלים.
- כל זוג אומר כמה תיקונים ידניים עשה (נרשם ב-`manual.csv`, ראו `docs/MEASUREMENT.he.md`).
- מחלקים `FEEDBACK-FORM.he.md` (5 דק'), אוספים לפני שיוצאים.

## מה המנחה מתעד אחרי הסדנה
זמנים בפועל לכל שלב, כשלי חיבור, שאלות שחזרו, מי ביקש להמשיך כחלוץ. נכנס לטבלת "פילוט משתמשים" (`docs/rollout/PILOT-USERS.he.md`).
