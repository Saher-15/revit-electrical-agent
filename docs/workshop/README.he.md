## לפני הסדנה (בוצע לכל משתתף)
1. התקנה (30 דק'): `install-electrical.ps1` או חבילת release; כניסה ל-Claude; העתקת ה-skill.
2. `office.json` מולא ב-families של המשרד (`get_available_family_types`).
3. חשבון Claude Team לכל משתתף; מדיניות עבודה על עותק מקומי של מודל ענן.

## מערך 90 דקות
| דק' | נושא |
| --- | --- |
| 0-15 | מושגים: יחידה, תכונה, כלל. דוגמה אחת ← שאר המודל. שערי אישור, מה אסור (Save/Sync). |
| 15-30 | הדגמה חיה על מודל הדוגמה: snapshot ← קריאת הדוגמה ← למידה ← הצעה. |
| 30-60 | תרגול: כל משתתף מתכנן חדר אחד; Claude ממשיך את הקומה; קוראים את סיבות הוזז/נשמט. |
| 60-80 | ביקורת: מתקנים נקודה, מנסחים כלל, בודקים שהוא חל על כל הדירות. |
| 80-90 | מדידה: `run-report.json`, כמה תיקונים ידניים, שאלות. |

אפשר להאריך לחצי יום (משרד חיצוני): להוסיף עריכת `office.json` בידי המשתתפים ופרויקט ראשון עם `get_project_setup`.

## תרגילים
1. **חדר אחד:** תכננו חדר שינה. מה Claude הבין מהחדר (מיטה, שידה, דלת)? תקנו שגיאת קריאה דרך מילות המפתח ב-`office.json`.
2. **סיבות:** מצאו 3 נקודות שהוזזו או נשמטו וקבעו אם הסיבה נכונה.
3. **כלל חדש:** נסחו כלל גובה, וודאו שהוא נכתב ל-`RULES.proposed.md` עם מקור.
4. **כשל מכוון:** בקשו מ-Claude להניח במודל בלי אישור; הוא חייב לעצור (שער אישור).

## קליטת משרד חדש (אחרי הסדנה)
התקנה 30 דק' ← `office.json` שעה ← כללי פרויקט ← פיילוט קומה אחת מול תכנון ידני (`review_model` + חוברת השוואה) ← go-live.
קריטריון הצלחה: קומה מאושרת ללא שינוי קוד.
